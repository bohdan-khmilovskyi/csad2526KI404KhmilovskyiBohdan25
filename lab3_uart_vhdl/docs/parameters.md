# Параметри UART

| Параметр | Значення | Примітка |
|---|---:|---|
| Варіант | 25 | UART, VHDL |
| Формат кадру | 8N1 | 1 стартовий, 8 інформаційних і 1 стоповий біт |
| Порядок передавання | Молодший біт першим | — |
| Парність | Відсутня | — |
| Системна частота під час синтезу | 50 МГц | `G_CLK_FREQ_HZ = 50000000` |
| Задана швидкість UART | 9600 бод | `G_BAUD_RATE = 9600` |
| Тактів на біт | 5208 | `C_CLKS_PER_BIT = 50000000 / 9600` з цілочисельним діленням |
| Розрахункова швидкість | 9600,61 бод | `50000000 / 5208` |
| Системна частота тестбенча | 1 МГц | `C_CLK_FREQ_HZ = 1000000` |
| Швидкість UART у тестбенчі | 100 кбод | 10 тактів на один біт |

Формат 8N1, системну частоту 50 МГц і швидкість 9600 бод прийнято для цієї реалізації. У тестбенчі застосовано окремі прискорені параметри, які не змінюють параметрів синтезованого верхнього модуля.
