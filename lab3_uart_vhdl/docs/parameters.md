# Параметри UART

| Параметр | Значення | Примітка |
|---|---:|---|
| Протокол | UART | Варіант 25 |
| Мова | VHDL | Варіант 25 |
| Формат кадру | 8N1 | Прийняте базове припущення |
| Стартовий біт | 1 біт, 0 | UART idle = 1 |
| Дані | 8 бітів, LSB first | Молодший біт першим |
| Парність | Відсутня | N у форматі 8N1 |
| Стоповий біт | 1 біт, 1 | Повернення до idle |
| Базова частота верхнього модуля | 50 MHz | Тимчасове проєктне значення |
| Базова швидкість | 9600 baud | Тимчасове проєктне значення |
| Тестбенч: частота | 1 MHz | Прискорена симуляція |
| Тестбенч: швидкість | 100 kbaud | 10 тактів на біт |

Методичка не визначає параметри електричного рівня, конкретну FPGA, системну частоту або швидкість UART. Перед синтезом необхідно уточнити цільову ПЛІС та тактову частоту.
